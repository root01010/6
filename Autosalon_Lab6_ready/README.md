# Лабораторна робота №6 — Наслідування та Поліморфізм

## Тема
Наслідування та поліморфізм у C#.

## Що реалізовано
1. Обов'язкове завдання №1:
   - абстрактний клас `Vehicle`;
   - класи `Car`, `Bicycle`, `Airplane`;
   - інтерфейс `Refuelable`;
   - демонстрація поліморфізму через список `List<Vehicle>`.

2. Обов'язкове завдання №2:
   - індивідуальна ієрархія `PublicTransport`;
   - класи `Bus`, `Tram`, `Metro`;
   - інтерфейс `IRouteInfo`;
   - демонстрація наслідування та перевизначення методів.

## Як запустити

```bash
cd src
dotnet run
```
